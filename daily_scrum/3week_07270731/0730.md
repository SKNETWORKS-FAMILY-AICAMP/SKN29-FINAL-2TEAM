## 스크럼 회의록

### 1. 화면 설계 마무리 및 운영자 페이지 기능 구현

**진행 내용**

* 프론트엔드 화면 설계와 화면별 목업 작업을 마무리함
* 운영자 페이지의 화면 설계를 완료하고, 기능 구현 작업을 진행함
* 역할별 화면의 구현 상태를 공유하고 남은 작업을 확인함

**주요 논의**

* 화면 목업 완료와 실제 기능 구현 완료는 구분해 관리하기로 함
* 운영자 페이지는 역할별 접근 범위와 운영 정책을 고려하여 후속 기능을 연결해야 함

---

### 2. 비정형 문서 파싱 모델 테스트

**진행 내용**

* 비정형 문서 파일을 처리하는 파싱 모델을 계속 테스트함
* 테스트 결과를 바탕으로 문서 유형별 처리 가능 여부와 보완 지점을 확인함

**주요 논의**

* 파싱 모델의 결과는 입력 문서 품질과 형식에 영향을 받을 수 있으므로, 결과를 무조건 확정하지 않고 검증 절차를 둬야 함
* 추출 데이터가 후속 분석에 사용될 수 있도록 누락·오류 사례를 지속적으로 확인하기로 함

---

### 3. 계정 로그인 및 Google 계정 연동 작업

**진행 내용**

* 팀원 사용 가능 로그인 흐름을 점검하고 관련 구현을 진행함
* 사용자 Google 계정 정보를 활용한 계정 연동 작업을 진행함

**주요 논의**

* 계정 연동은 사용자 확인 없이 자동 확정하지 않고, 연결 상태와 권한 범위를 확인할 필요가 있음
* 로그인·계정 연동 기능은 화면 구현과 함께 실제 인증 및 권한 정책에 맞춰 검증해야 함

---

### 금일 진행 결과

* 프론트엔드 화면 설계와 목업 작업을 마무리하고 운영자 페이지 기능 구현을 진행함
* 비정형 문서 파싱 모델을 테스트하며 보완이 필요한 사례를 확인함
* 팀원 로그인 흐름과 사용자 Google 계정 연동 작업을 진행함

---

### 다음 진행 예정

* 운영자 페이지의 남은 기능을 구현하고 역할별 화면 흐름을 검증함
* 비정형 문서 파싱 결과를 추가 테스트하여 예외 처리와 데이터 품질 기준을 보완함
* 로그인 및 계정 연동 기능의 인증·권한 처리와 사용자 확인 절차를 점검함
