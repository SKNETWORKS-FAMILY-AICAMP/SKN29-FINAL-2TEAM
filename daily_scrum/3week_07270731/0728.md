## 스크럼 회의록

### 1. 기획·설계 자료 정리 및 화면 구현 방향 논의

**진행 내용**

* 기획서와 설계 자료를 검토하여 개발에 필요한 요구사항과 우선순위를 정리함
* 화요일까지 기획서 기반 React 화면 구현을 진행하고, 이후 화면 연결과 구현 흐름을 점검하기로 함
* 화면 구현 과정에서 확인이 필요한 사항은 수시로 공유하여 논의하기로 함

**주요 논의**

* 요구사항의 근거가 되는 기획·설계 자료를 우선 확인한 뒤 구현 범위를 결정함
* 화면별 구현 완료 여부와 후속 연결 작업을 구분해 관리할 필요가 있음

---

### 2. 데이터 모델·백엔드 기초 구조 정비

**진행 내용**

* HR 데이터 구조를 설계하고 목업 데이터를 활용해 데이터 모델 검토를 진행함
* 백엔드 데이터베이스 구조를 정리하고, 테이블 설계와 목업 데이터의 정합성을 점검함
* 기획에 기재된 방식과 기존 모델 사이의 차이를 확인하여 필요한 보완 항목을 검토함

**주요 논의**

* 데이터 모델은 화면 구현과 API 연동의 기준이 되므로, 초기 목업 단계에서도 필수 항목을 명확히 해야 함
* 비정형 문서 처리 및 업무량 분석에 필요한 데이터 항목은 구현 전에 재확인할 필요가 있음

---

### 3. 프로젝트 문서화 및 협업 준비

**진행 내용**

* 기획·설계 문서를 검토하며 부족한 부분을 보완하고, 문서 피드백 사항을 반영함
* 추후 멘토링에서 피드백을 받을 수 있도록 중간 발표 PPT 개요를 작성함
* 팀원별 구현 진행 상황을 공유하고, 후속 작업의 우선순위를 조정함

**주요 논의**

* 멘토링에서는 문서 파싱·분석 로직과 코드 구조를 중점적으로 점검받기로 함
* 발표 자료는 구현 현황뿐 아니라 프로젝트의 문제 정의, 데이터 흐름, 향후 계획이 보이도록 구성할 필요가 있음

---

### 금일 진행 결과

* 기획·설계 자료를 기준으로 화면 구현과 데이터 모델 정비의 우선순위를 정리함
* HR 데이터 모델 및 목업 데이터 기반의 데이터베이스 구조 검토를 진행함
* 문서 보완과 중간 발표 PPT 개요 작성을 통해 멘토링 준비를 시작함

---

### 다음 진행 예정

* React 화면 구현을 이어가고, 화면별 연결 및 보안 관련 요구사항을 점검함
* 데이터 모델과 목업 데이터의 정합성을 확인하며 비정형 문서 처리 로직을 보완함
* 멘토링 피드백을 반영할 수 있도록 중간 발표 자료와 검토 항목을 정리함
