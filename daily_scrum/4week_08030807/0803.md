토요일 멘토링에서 받은 피드백을 반영해 전체 시스템의 핵심 처리 흐름을 구체화하는 작업을 진행했습니다.

먼저, 커넥터를 통해 데이터를 받아 파서 → 청킹·리트리버 → 에이전트까지 이어지는 전체 처리 흐름을 사용할 수 있도록 구조를 정리했습니다.

다음으로 업무량 계산은 기존 계산 방식을 다시 검증하고 수정하여 프로젝트에 적용했습니다.

청킹과 리트리버에서는 하이브리드 청킹 적용 시 발생하는 문제점을 분석하고 해결 방안을 검토했으며, 임베딩 작업도 함께 진행했습니다. 또한 문서를 청크 단위로 저장하고, 질문과 관련된 청크만 검색해 에이전트에 전달하는 구조를 설계했습니다.

에이전트는 업무 분배 로직을 구체화했습니다. 업무량 계산을 필수 Tool로 연결하고, LangGraph의 노드와 엣지를 다시 설계하여 AI가 필요한 기능을 활용할 수 있도록 구조를 정리했습니다.

마지막으로 발표 자료는 현재 구현된 시스템 파이프라인에 맞게 구조를 수정해 실제 구현 내용과 발표 내용을 정리했습니다.
