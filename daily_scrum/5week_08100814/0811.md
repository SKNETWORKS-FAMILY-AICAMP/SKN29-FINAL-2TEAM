## 스크럼 회의록 (2026-08-11 화)

### 1. AWS 공유 환경 1단계 구축 (준)

팀원마다 자기 노트북에 Postgres 를 띄워 개발하던 구조를 걷었다. 스키마를 바꾸면
각자 수동 `ALTER` 를 돌려야 했고, A 가 등록·색인한 문서를 B 는 못 봤다.

**진행 내용**

* RDS PostgreSQL 생성 → `DB/schema.sql` 과 People 목업 적용
* S3 버킷 생성 (퍼블릭 액세스 차단·버저닝 활성화)
* IAM 사용자와 S3 전용 정책 발급
* EC2 는 **인스턴스만 만들어 두고** Docker·SSH 까지만 — 배포는 OAuth 방향이
  정해진 뒤로 미뤘다
* 팀원 `.env` 교체 안내, 로컬 `db` 컨테이너 내리기 확인

**주요 논의**

* RDS 만 공유하면 절반만 풀린다. 문서 메타·청크·임베딩은 DB 에 있어 합쳐지지만
  **원문 파일은 각자 로컬 디스크에 남는다** — S3 가 붙어야 원문 열람이 된다
* 접속 계정 정보는 **저장소가 아니라 팀 채널로만** 전달한다

### 2. Agent Platform 스키마 확장

* 에이전트·실행 기록·MCP 서버 테이블을 추가 (`agent`, `agent_run`, `tool_call`,
  `mcp_server` 등)
* 문서 메타 파이프라인과 2단계 검색을 붙였다

### 3. 에이전트 빌더 착수 (김지훈)

* 에이전트 도구 카탈로그 선택 UI 초안
* 생성·검증 흐름 설계
