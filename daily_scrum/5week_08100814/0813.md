### 4. 홈페이지 고도화 (준)

운영자 콘솔에서 **볼 수만 있고 하지는 못하던 조치 네 가지**를 열었다.

| 열린 것 | |
|---|---|
| 운영자 권한 부여·회수 | |
| 팀 소유자 이전 | |
| 팀 에이전트·실행 기록 조회 | |
| **커넥터 강제 해제** | 그동안 제품 어디에도 없어서, **토큰이 유출돼도 고객도 운영자도 끊을 수 없었다** |

멘토링 피드백대로 **모델 등록 방식을 뒤집었다.** 사용자가 직접 API 키를 붙이는
대신, 회사가 요청하면 운영자가 등록하는 흐름으로 바꾸고 제공자를 셋으로 넓혔다.

**전체 코드 정리.** 다중 에이전트로 저장소를 훑어 폐기된 기능의 잔해와 죽은 코드를
찾아 **1만 3천 줄**을 걷어냈고, 문서가 실제 코드와 어긋난 곳도 함께 맞췄다.

MCP 서버 등록·수정 기능과 시연용 MCP 서버도 붙였다.
