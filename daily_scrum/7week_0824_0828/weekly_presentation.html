여러 단계의 업무도 현재 상태와 완료 결과가 분명하게 보입니다.

  • 사용한 도구와 단계별 완료 상태
  • 생성된 결과물 확인
  • 표·목록·출처·복사 기능 개선
  • 대화 검색과 날짜별 이동
최종 답변뿐 아니라, 어떻게 처리됐고 무엇이 만들어졌는지까지 보여줍니다.
AI에게 여러 단계의 업무를 요청했을 때 작업 과정과 완료 결과를 한눈에 확인할 수 있도록 채팅 화면을 개선했습니다. 화면처럼 원본과 수정본 비교, 작성자 정보 제거를 요청하면 에이전트가 문서 조회와 파일 비교, 정보 제거 작업을 순서대로 수행합니다. 사용자는 몇 개의 도구가 실행됐는지, 각 작업이 완료됐는지, 어떤 결과물이 만들어졌는지 확인할 수 있습니다. 답변의 표와 목록, 출처 표시를 보완했고 긴 대화의 검색과 날짜 이동도 추가했습니다.

Document Parsing

PDF 속 이미지도
검색 가능한 정보로

한국어 VLM 선택영어 중심 기본 모델 대신 한국어가 안정적이고 할루시네이션이 적은 Qwen2.5-VL을 적용했습니다.
주변 문맥 함께 제공제목·캡션·앞뒤 문장을 함께 전달해 이미지의 문서 내 의미를 보완합니다.
이미지별 추출 기준차트는 축·단위·수치, 장치 구성도는 명칭·기호·연결, 표는 행·열 관계와 주요 값을 추출합니다.
복잡한 판단보다, 화면에서 확인되는 명확한 정보 추출에 집중했습니다.
PDF 안의 이미지도 검색에 활용할 수 있도록 이미지 내용을 한국어 설명으로 생성해 문서에 추가했습니다. Docling의 기본 모델은 영어 중심이라, 비교 결과 한국어 출력이 안정적이고 할루시네이션이 적은 Qwen2.5-VL을 선택했습니다. 이미지 주변 제목과 캡션, 앞뒤 문장도 함께 전달해 문맥을 보완했습니다. 차트는 축과 단위, 수치를 보고 장치 구성도는 부품명과 기호, 연결 관계를 확인하며 표는 행과 열의 관계와 주요 값을 추출하도록 이미지 종류별 프롬프트를 적용했습니다.

VLM은 복잡한 판단을 요구할수록 이미지에 없는 내용을 만드는 경향이 있어, 직접 확인되는 수치와 명칭, 연결 관계 중심으로 출력 범위를 제한했습니다. 또 모델의 시맨틱 태그와 불필요한 형식이 결과에 섞이는 문제가 있어 저장 전에 제거하고 형식을 정규화했습니다. 그 뒤에도 할루시네이션이 남을 수 있어 검증 게이트를 추가했습니다. 문장 반복, 비정상적인 다른 언어 출력, 프롬프트나 입력 문맥 노출을 검사하고 통과한 설명만 최종 이미지 디스크립션에 넣습니다.

에이전트 평가는 실제 업무 상황을 시나리오로 구성했습니다. 문서 기반 업무의 정확성, 프롬프트 인젝션과 정보 유출 방어, 사용자 승인 처리, 도구 장애 대응을 확인했습니다. 도구 호출이나 권한 위반, 외부 시스템 변경처럼 실행 기록으로 확인할 수 있는 항목은 규칙으로 판정했습니다. 답변이 문서 근거와 일치하는지, 확인되지 않은 내용을 단정하지 않았는지는 정해진 기준을 사용하는 별도의 AI 평가 모델로 판정했습니다.
