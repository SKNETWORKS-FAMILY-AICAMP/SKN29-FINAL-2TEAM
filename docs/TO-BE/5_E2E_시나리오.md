# 대표 E2E 시나리오

> 이 하나의 흐름이 안정적으로 동작하는 것이 최종발표의 중심.

**사용자**: "이번 프로젝트 문서를 참고해서 업무를 정리하고 Jira 프로젝트에 등록해줘."

1. Agent가 요청 분석
2. Google Drive Connector로 관련 문서 검색
3. 필요한 문서 Parsing / Retrieval
4. Task Extraction Agent 실행
5. (필요 시) 업무 분배 Agent 활용
6. 사용자에게 결과 확인
7. Jira MCP Tool 호출
8. Jira Project / Issue 생성
9. 완료 결과·근거 반환

이 흐름 하나로 Connector · Document Processing · Agent · MCP · Tool Calling ·
Project Operation을 모두 시연한다.
