## 공통 주의사항

- 스타일: **CSS Modules + `tokens.css` 변수만** (Tailwind 없음 — 기존 규칙).
  공용 컴포넌트 20종(`components/` — Button·Card·Badge·Modal·StepIndicator 등)
  위에 얹는다. 새 색·간격 값을 임의로 만들지 말고 tokens 사용.
- 경로는 전부 `routes.ts`의 `PATHS` 상수로 (8/10 단일화 완료 — 문자열 직접
  사용 금지).
- `npm install`은 `frontend/`에서만. `git add .` 금지(CRLF).
- **G3 금지 목록 — 지우면 안 됨**: `/tasks/extraction`·`/tasks/distribution/documents`
  (Chat E2E 통과 전 데모 안전망), `/dashboard` 라우트, `/projects`의 「업무 분배
  시작」 버튼. 삭제는 별도 지시로.
- **멘토링 대기 — 구현 제외**: 기본 에이전트 「복제」 버튼 / 공개 범위 「나만
  보기」 / 확인 카드 「다시 정리해줘」. Figma에 빨간 주석이 달린 요소들 —
  8/12 결정 후 별도 지시.

  화면에만 남긴다.

- `SettingsPage`(46줄 래퍼)를 탭 컨테이너로 개편: 팀 / Connector / MCP /

  칩(백엔드 단계 6 API 계약 — 그 전엔 mock). Model 탭·권한 탭 = 골격(정적).
- 문서 화면(`63:1136` — 팀 범위, 상태 칩 4종+범례·요약 열·삭제 파일 정리):

- 온보딩 2스텝 개편(`48:1224`): Jira 스텝을 필수에서 빼고 "나중에 하기" —
