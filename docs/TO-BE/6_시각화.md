## ③ 대표 E2E Flow (시퀀스)

```mermaid
sequenceDiagram
    actor U as 사용자
    participant C as Chat
    participant H as Harness
    participant R as Retrieval<br/>(pgvector)
    participant X as 추출 Agent<br/>(Pre-built)
    participant M as Jira MCP

    U->>C: "문서 참고해서 업무 정리하고<br/>Jira에 등록해줘"
    C->>H: 요청 전달
    H->>H: STEP 1 계획 수립
    H->>R: STEP 2-3 문서 검색·청크 확보
    H->>X: STEP 4 추출 실행
    X-->>C: NDJSON 스트리밍 (단계·검색어·근거 수)
    C->>U: STEP 6 업무 목록 + 근거(E1~E20) 확인 요청
    U->>C: 업무별 체크 후 승인
    H->>M: STEP 7-8 Project/Issue 생성
    alt 일부 실패
        M-->>H: 17/20 성공
        H->>C: PARTIAL_RESULT — 성공분 보존,<br/>실패 3건 사유 + 재시도 버튼
    else 전부 성공
        M-->>H: 20/20 성공
    end
    H->>C: STEP 9 이슈 링크 + 업무별 근거 반환
```

## ⑤ Agent Harness Architecture

```mermaid
flowchart TD
    chat["Chat (스트리밍 — 기존 NDJSON 프로토콜)"] --> loop

    subgraph harness["Agent Harness  ※ 신규 작성 — services/harness (기존 재사용은 NDJSON 규약·이벤트 타입·실행 레코드 패턴 3종)"]
        loop["Agent Loop<br/>판단 → Tool 선택 → 실행 → 확인 → 반복/종료"]
        reg["Tool Registry<br/>내장 Tool + MCP Tool<br/>Agent별 허용 목록"]
        ctx["Context 관리<br/>대화 이력 + Retrieval 주입<br/>(Compaction·장기 Memory는 구조만)"]
        perm["Permission<br/>팀 경계(_require_team) 위에<br/>Agent 사용/생성 권한"]
        log[("agent_run · tool_call<br/>실행 로그 — 개발 첫 주")]
    end

    loop --> reg
    loop --> ctx
    loop -.-> perm
    loop --> log

    reg --> builtin["내장 Tool<br/>Retrieval · 리포트 생성"]
    reg --> mcpc["MCP Client"]
    mcpc --> jira["Jira MCP Server"]
    builtin --> data["Data Layer (기존)"]
    loop --> model["Model 연결<br/>gpt-5.6 luna/sol — 교체 가능 구조"]
    log --> eval["평가 자동 집계<br/>(4_평가_설계)"]
```
