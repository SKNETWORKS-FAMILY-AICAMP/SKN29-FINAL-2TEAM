## 한 줄 정의

기업의 데이터와 업무 도구를 연결하고, 비개발자가 프로젝트 운영에 필요한
AI Agent를 직접 만들고 활용할 수 있도록 하는 Agent 기반 Project Operation Copilot.

- Platform = 우리가 만드는 제품 (Builder + Harness + Connector/MCP)
- 업무 추출·분배 = Platform 위의 Pre-built Agent / 대표 데모
