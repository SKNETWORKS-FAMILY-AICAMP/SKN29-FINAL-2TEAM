## 3. 문구가 아니라 사실이 틀렸던 것

**카드 ③ 본문이 「Jira에 등록하기 전」으로 남아 있었다.** 2026-08-12 에 **등록은
우리 플랫폼(`task`)이 먼저**로 바뀌었고 히어로 목업은 그때 같이 고쳐졌는데, 이
카드는 안 고쳐져 **랜딩 한 화면 안에서 두 말이 어긋나 있었다.** 공개 주소의 첫
화면이라 여기서 어긋나면 제품이 아직 Jira 부속으로 읽힌다.

**개인정보처리방침 링크가 공개 화면 어디에도 없었다.** Google 커넥터 심사가 이
주소를 직접 여는데(`routes.ts` 의 `PATHS.privacy` 주석) 주소를 알아야만 갈 수

| 자리 | 문서 | 코드 | 판단 |
|---|---|---|---|

## 5. 레이아웃 — 문구가 아니라 「화면이 비어 있던」 것

1. **히어로 좌측이 비었다.** 목업이 세로로 길어 카피가 세로 가운데로 밀리고
   위아래에 120px 씩 죽은 공간이 생겼다 → 위 정렬 + 근거 3줄.
2. **전 섹션이 중앙 정렬에 같은 패딩(88px)이었다** → 좌측 정렬을 기본으로,
   중앙 정렬은 마감 CTA 하나만 남겼다.
3. **기능 카드가 시각물 → 제목 순서였고 시각물이 `height: 148px` 에 잘렸다**
   (카드 ②·③ 내용이 169px·134px 라 **행 한가운데서** 썰렸다) → 제목 → 본문 →
   시각물 순으로 뒤집고 높이 제한을 없앴다.
4. **마감 CTA 배경이 `--color-primary-soft`(네이비 6%)라 사실상 연회색이었다**
   → 네이비를 꽉 채운 유일한 밴드로 만들었다. 페이지에서 여기만 어둡다.
5. **작동 방식이 회색 카드 4장이라 한 줄기로 안 보였다** → 카드를 없애고 위쪽
   선 하나로 꿴 레일.

### 같이 고친 버그

- **모바일에서 섹션 2·4 만 좌우 48px 로 남아 있었다.** 미디어 쿼리 선택자 목록에
  `.bandWhite` 가 빠져 있었다. 목록에 이름을 더하면 다음에 또 빠지므로 **밴드
  여백을 `.page` 의 `--band-x`/`--band-y` 변수로 묶었다** — 새 섹션을 넣어도
  자동으로 따라온다.
- `.bandMuted` 는 정의가 없는 **죽은 선택자**였다(구 랜딩 잔재). 삭제했다.
- **네비 로고가 본문 그리드와 48px 어긋나 있었다** — `.navInner` 만 `max-width`
  안에 패딩을 같이 가져 콘텐츠 폭이 `max-width - 패딩` 이 됐다.
- **한국어가 어절 한가운데서 줄바꿈됐다**(「지어내 / 지 않고」·「멈추지 않 / 고」)
  → `word-break: keep-all` + `overflow-wrap: break-word`.

### 토큰

`tokens.css` 에 7개를 더했다. **색은 하나도 안 건드렸다** — 리뉴얼이 바꾼 것은
색이 아니라 여백·정렬·타이포 위계다.

- 간격 `--space-16`(64) · `--space-20`(80) · `--space-24`(96) — 섹션 사이 전용
- 타이포 `--text-display`(46) · `--text-title`(34) · `--text-lead`(18) — 큰 제목이
  필요한 공개 화면용. 앱 화면은 안 쓴다
- 그림자 `--shadow-float` — 히어로 목업. `--shadow-card` 계열은 넓은 여백 위에서
  있는지도 안 보인다

## 6. 시각·움직임

- 움직임은 **등장 한 번, 스크롤 한 번**뿐이고 동작이 같다. 목업 안에서는 대화

  IntersectionObserver 를 쓰면 스크립트가 못 돌아 내용이 안 보이는 사고가 가능해진다
- `prefers-reduced-motion: reduce` 에서 전부 꺼진다. 움직임 규칙을
  `no-preference` 안에만 둬서 **기본값이 「안 움직임」**이다
