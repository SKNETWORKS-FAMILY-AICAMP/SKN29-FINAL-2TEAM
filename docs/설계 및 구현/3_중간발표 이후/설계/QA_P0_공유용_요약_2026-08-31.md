## 1-1. 이번 QA에서 P0라는 뜻

P0는 문제가 생기면 서비스 사용이나 시연을 막을 수 있는 가장 중요한 기능입니다. 이 문서에서는 로그인·권한, 채팅, 승인·거절, 파일, 문서 검색·이미지 검색, 팀 데이터 분리, 운영자 접근을 P0로 확인했습니다.

판정은 다음처럼 구분했습니다.

- `PASS`: 기대한 결과가 나옴
- `FAIL`: 실행했지만 기대와 다름
- `BLOCKED`: 환경·권한·데이터가 없어 끝까지 확인하지 못함
- `NOT RUN`: 아직 실행하지 않음

이번 결과의 `PASS`는 로컬에서 실제 데이터와 화면을 사용해 확인한 결과이며, 배포의 `NOT RUN`을 성공으로 간주하지 않습니다.

## 3. 발견한 문제와 수정 내용

### 문제 1. 문서 검색 답변에 일부 내용이 빠짐

여러 문서 블록을 하나의 검색 청크로 묶었을 때, 검색은 전체 내용을 사용했지만 모델에는 첫 번째 블록만 전달되고 있었습니다. 그래서 문서 뒤쪽에 있는 담당자·위험 등급 같은 내용이 검색 결과에서 빠질 수 있었습니다.

수정 내용:

- `backend/db/document_pipeline.py`의 `search_hybrid` 반환값을 수정했다.
  - 일반 텍스트: 첫 블록이 아니라 `chunk.search_text` 전체 반환
  - Picture: 설명 텍스트를 반환하지 않고 `NULL`로 분리
- `tests/test_document_pipeline.py`, `tests/test_document_search.py`에 다중 블록 누락과 Picture 텍스트 노출 방지 회귀 테스트를 추가했다.

결과: 고유 문구·위험 등급·담당자 질의가 정확히 답변되는 것을 확인했습니다.

### 문제 2. 이미지 검색이 실제로 연결됐는지 확인 필요

코드만으로는 이미지 검색이 동작해도 실제 PDF에서 crop이 만들어지고 모델이 읽는지는 알 수 없었습니다.

확인 내용:

- 소형 LS 제품 PDF 처리 성공
- Picture block 3개 생성
- 원본 PDF에서 PNG crop 반환 성공
- 이미지 검색 도구가 crop 이미지를 모델 입력으로 전달
- `gpt-5.6-luna`가 도면을 직접 읽고 위치를 설명
- 불명확한 단자 순서는 추측하지 않고 모른다고 답변

수정·검증 파일:

- `services/harness/registry.py`: `document_search_with_images`가 상위 Picture 근거를 crop image part로 구성하는지 확인
- `services/document_pipeline/picture_crop.py`: `block_id·doc_id·revision` 서명 URL 계약 확인
- `apps/projects/api_views.py`: 현재 revision·삭제·접근 회수·Picture 여부를 다시 확인한 뒤 PNG 반환
- `tests/test_picture_crop.py`: 서명·변조·만료·crop 응답 회귀 테스트

## 4. 큰 PDF에서 확인된 한계

235쪽 LS 인버터 매뉴얼은 파일 업로드와 RunPod 처리는 진행됐지만, 처리 결과를 가져오는 단계에서 실패했습니다.

현재 판단:

- PDF 자체가 잘못된 것은 아님
- 작은 PDF는 정상 처리됨
- RunPod Serverless의 `/run` 작업은 요청·결과 payload 크기 제한을 받는다.
- 이번 문서는 RunPod가 원문을 내려받고 파싱을 완료했지만, 전체 파싱 결과를 반환하는 단계에서
  Django가 빈 결과로 받았다. 즉 입력 다운로드·파싱보다 **출력 반환 크기**에서 실패한 정황이다.
- 원시 worker output이 보존되지 않아 정확한 초과 크기는 확인할 수 없지만, 235쪽 결과가 현재
  “전체 결과를 응답으로 반환”하는 구조와 맞지 않는다는 강한 신호다.

권장 방향:

- 처리 결과 전체를 RunPod 응답으로 보내지 않음
- worker가 결과 JSON을 DB·객체 저장소에 저장
- RunPod 응답에는 작업 ID와 결과 위치만 반환
- Django가 저장된 결과를 읽어 후속 색인·상태 변경을 진행

이 부분은 별도 구조 개선 과제로 분리하는 것이 좋습니다.
