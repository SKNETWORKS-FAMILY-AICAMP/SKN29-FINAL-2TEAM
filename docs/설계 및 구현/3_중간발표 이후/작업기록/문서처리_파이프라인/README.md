# 문서처리 파이프라인 작업기록 안내

이 폴더는 문서 입력부터 근거 검색까지 이어지는 문서 처리 파이프라인의 설계,
구현, 실험, 평가 기록을 역할별로 모으는 상위 영역이다.

```text
문서 입력
  → 파싱·후처리
  → 블록·청크 구성
  → 임베딩·색인
  → 검색 전략
  → 근거 전달·평가
```

## 현재 하위 영역

- `검색_전략/`: 키워드·벡터·하이브리드 검색, 검색 데이터 계약, 검색 품질 평가와
  관련된 정본 및 상세 작업기록
- `Docling_후처리_고도화/`: Docling 완성 JSON 이후의 국소 읽기 순서 보정,
  list-item 헤딩 승격 실험, AutoResearch-lite 기반 threshold 검증, Worker 통합
  범위와 상세 작업기록

각 하위 영역은 담당 범위의 실험·설계·검증 기록을 담는다. 문서가 존재한다는 것이
정식 Docling 파싱·청킹·임베딩의 제품 통합 완료를 의미하지는 않으며, 실제 병합
상태와 기본 활성화 여부는 각 영역의 README와 통합 문서에서 별도로 확인한다.

## 문서 배치 기준

- 팀원이 현재 구조와 결론을 빠르게 확인해야 하는 문서는 해당 역할 폴더의 정본
  요약으로 둔다.
- 시간순 수행 내용, 시행착오, 검증 로그와 의사결정 근거는 상세 작업기록으로 둔다.
- 하나의 작업이 여러 단계에 걸치면 실제 변경의 주 책임을 기준으로 배치하고,
  연관 단계는 문서 안에서 링크하거나 경계를 설명한다.
- 개인 로컬 문서, 자격 증명, 공용 DB 주소와 원문 민감정보는 포함하지 않는다.
