스킬 등록 과정을 자세히 보시면 먼저 사용자가 어떤 스킬을 만들지 문장을 입력합니다. 한 문장이어도 됩니다. 그다음 바로 등록하는 게 아니라, 이 스킬이 필요한 요청에서는 제대로 실행되고 필요하지 않은 요청에서는 잘못 실행되지 않는지를 확인합니다. 한 번 등록된 스킬은 이후 여러 사용자 요청에 영향을 줄 수 있기 때문에, 잘못 실행되면 오히려 답변 품질을 떨어뜨릴 수 있습니다. 그래서 실제 환경과 분리된 검증 환경에서 먼저 테스트하고, 검증을 통과한 스킬만 최종 등록하도록 했습니다.
