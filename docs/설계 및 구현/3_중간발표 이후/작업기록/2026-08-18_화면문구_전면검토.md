# 2026-08-18 — 화면 문구 전면 검토

PM 지시로 제품 전체의 화면 문구를 훑었다. 주석은 대상이 아니다 — 개발자가
읽는 글이고, 화면에 안 나온다.

**바꾼 기준 셋.**

| 무엇 | 왜 | 무엇으로 |
|---|---|---|
| 낫표 `「」` | 이 저장소는 이미 작은따옴표를 쓴다(공지 삭제 확인창) | `‘ ’` |
| 이어붙임표 `—` | 한 문장에 두 생각을 붙여 놓는다. 읽는 사람이 두 번 읽는다 | 자리마다 다시 씀 |
| 만드는 사람 말투 | 「우리가」·「저희가」는 만드는 쪽 자리에서 쓴 말이다 | 걷어냄 |

**이어붙임표는 기계로 안 바꿨다.** 그 부호가 자리마다 하는 일이 다르다 —
문장을 나누는 자리, 이름과 값을 잇는 자리, 목록을 여는 자리. 하나씩 다시 썼다.

아래가 바꾼 전부다.
