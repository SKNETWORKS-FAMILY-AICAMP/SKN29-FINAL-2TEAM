# 09. 7단계 세부 01 — Child 관계 검증

## Child 관계 검증에서 하는 일

1. Root에 연결된 Child 정보를 받는다.
2. 각 Child가 활성 상태인지 확인한다.
3. 현재 사용자가 Child를 실행할 수 있는지 확인한다.
4. Child가 또 다른 Child를 가지고 있는지 확인한다.
5. 에이전트 관계에 순환 구조가 있는지 확인한다.
6. 문제가 있으면 Runtime Graph 조립을 중단한다.

## 전체 동작 흐름

```text
AgentRuntimeFactory.build() 시작
    ↓
Root의 Child 참조 목록 전달
    ↓
Child별 상태 확인
    ↓
├─ 비활성 Child
│  → 조립 중단
│
├─ 실행 권한 없는 Child
│  → 조립 중단
│
├─ Child가 다른 Child를 보유
│  → 위임 깊이 초과로 조립 중단
│
├─ 순환 위임 관계
│  → 조립 중단
│
└─ 모두 정상
   → Root 모델 준비 단계로 이동
```

## 검증에 사용하는 정보

```text
SubagentReference
├─ child_agent_id
├─ child_version_id
├─ alias
├─ delegation_description
├─ is_active
├─ can_execute
└─ has_subagents
```

| 값 | 검증 목적 |
|---|---|
| `child_agent_id` | Child 에이전트 식별 |
| `child_version_id` | 실행할 Child 버전 식별 |
| `is_active` | Child 연결이 활성 상태인지 확인 |
| `can_execute` | 현재 요청자가 실행할 수 있는지 확인 |
| `has_subagents` | 위임 깊이가 1단계를 넘는지 확인 |
| `alias` | Root가 Child를 선택할 때 사용할 이름 |
| `delegation_description` | Root가 위임 대상을 판단할 설명 |

## 허용되는 위임 구조

```text
Root
└─ Child
```

## 허용되지 않는 위임 구조

### 다단계 위임

```text
Root
└─ Child
   └─ Grandchild
```

### 순환 위임

```text
Agent A
→ Agent B
→ Agent A
```

## 검증 실패 시 결과

검증에 실패하면 다음 작업은 시작하지 않는다.

```text
모델 생성 안 함
도구 로딩 안 함
미들웨어 구성 안 함
Child Graph 생성 안 함
Root Graph 생성 안 함
agent_started 이벤트 생성 안 함
agent_run 기록 생성 안 함
```

잘못된 에이전트 관계를 발견하면 비용이 드는 모델·도구 조립 전에 중단한다.
