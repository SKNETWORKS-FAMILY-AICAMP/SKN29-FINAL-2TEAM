# 04. 3단계 — 가드레일과 실행 준비

## 3단계에서 하는 일

3단계는 두 작업을 동시에 진행한다.

### 3-A. 가드레일 검사

1. 사용자 원문을 외부 가드레일 검사에 전달한다.
2. 검사를 백그라운드에서 실행한다.
3. 검사 결과를 나중에 확인할 수 있는 `guard_check`를 만든다.

### 3-B. 실행 준비

1. 이전 채팅 기록을 조회한다.
2. 기록을 모델이 읽을 수 있는 `history`로 변환한다.
3. 계정과 세션 정보로 `RuntimeContext`를 만든다.
4. `agent_version_id`가 있으면 항상 `resolve_live_version_id()`를 호출한다.
   기본 채팅 에이전트인지 여부는 이 view 분기가 아니라 함수 내부 SQL
   (`is_default_chat = true`)이 판정하며, 해당하지 않으면 `None`을 돌려받아
   세션에 고정된 버전을 그대로 쓴다.

준비가 끝나면 다음 정보가 확정된다.

```text
guard_check
+ history
+ runtime_context
+ 실행할 agent_version_id
```

## 전체 동작 흐름

```text
2단계에서 확정된 입력
    ↓
가드레일 검사와 실행 준비를 동시에 시작
    ↓
├─ 3-A. 백그라운드 작업
│      ↓
│  사용자 원문을 가드레일에 전달
│      ↓
│  검사 결과를 담을 guard_check 생성
│
└─ 3-B. 메인 스레드 작업
       ↓
   이전 채팅 기록 조회
       ↓
   모델용 history 생성
       ↓
   계정 프로필 조회
       ↓
   RuntimeContext 생성
       ↓
   agent_version_id 있으면 resolve_live_version_id() 호출
   (기본 채팅 에이전트 여부는 함수 내부 SQL이 판정)
       ↓
   기본 채팅이면 최신 버전, 아니면 세션 고정 버전 유지
       ↓
두 작업의 준비 완료
    ↓
4단계에서 가드레일 결과 확인
```

## 지금까지 준비해 런타임에 전달하는 정보

가드레일을 통과하면 1~3단계에서 준비한 정보가 다음 형태로 런타임에 전달된다.

```text
AgentExecutor.run
├─ agent_id
├─ agent_version_id
├─ user_input
├─ context
├─ conversation_messages
└─ tool_refs_override
```

| 전달 정보 | 준비된 값 | 의미 |
|---|---|---|
| `agent_id` | `session["agent_id"]` | 실행할 에이전트 |
| `agent_version_id` | `session["agent_version_id"]` | 실행할 에이전트 버전 |
| `user_input` | `model_input` | 민감정보를 마스킹하고 필요하면 스킬 본문까지 결합한 현재 요청 |
| `context` | `runtime_context` | 요청자와 현재 실행 환경 |
| `conversation_messages` | `history` | 모델이 참고할 이전 대화 |
| `tool_refs_override` | `session["tool_refs_override"]` | 이 채팅에서 별도로 설정한 도구 목록 |

## `RuntimeContext` 내부 정보

```text
RuntimeContext
├─ account_id
├─ team_id
├─ role
├─ session_id
├─ project_id
├─ run_id
└─ parent_run_id
```

| 값 | 의미 |
|---|---|
| `account_id` | 현재 요청자 |
| `team_id` | 실행에 적용할 팀 범위 |
| `role` | 요청자가 팀장인지 팀원인지 |
| `session_id` | 현재 채팅 세션 |
| `project_id` | 채팅과 연결된 프로젝트 |
| `run_id` | 이번 실행을 식별하는 새 ID |
| `parent_run_id` | 상위 실행 ID이며 현재 루트 실행에서는 `None` |

## 런타임에 직접 전달되지 않는 정보

다음 값들은 준비 과정에서 사용되지만 `AgentExecutor.run()`의 실행 정보로 직접
전달되지는 않는다.

| 정보 | 사용처 |
|---|---|
| 사용자 원문 `text` | 채팅 기록 저장 |
| `guard_check` | 실행 허용 여부 판단 |
| `applied_skill` | 화면에 `skill_applied` 이벤트 표시 |
| 인증 토큰 | `account_id`를 확인한 뒤 런타임에는 전달하지 않음 |

정리하면 런타임은 다음 정보를 받는다.

```text
누가 실행하는가
+ 어느 팀과 프로젝트에서 실행하는가
+ 어떤 에이전트 버전을 실행하는가
+ 현재 요청이 무엇인가
+ 이전 대화가 무엇인가
+ 이 채팅에서 어떤 도구를 사용할 것인가
+ 이번 실행을 어떤 run_id로 추적할 것인가
```
