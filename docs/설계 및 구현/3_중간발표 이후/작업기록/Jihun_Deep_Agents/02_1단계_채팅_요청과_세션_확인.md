# 02. 1단계 — 채팅 요청과 세션 확인

## 1단계에서 하는 일

1. URL에서 `session_id`를 가져온다.
2. Bearer 토큰을 검증하고 `account_id`를 가져온다.
3. 요청 본문의 `content`를 검증한다.
4. DB에서 채팅 세션을 조회한다.
5. 요청자와 채팅 세션이 같은 팀인지 확인한다.

성공하면 다음 정보가 확정된다.

```text
session_id + account_id + content + session 정보
```

## 전체 동작 흐름

```text
클라이언트 요청
    ↓
채팅 메시지 URL 확인
    ↓
Bearer 토큰 인증
    ↓
메시지 content 검증
    ↓
채팅 세션 조회
    ↓
요청자와 세션의 팀 확인
    ↓
2단계로 이동
```

## 각 동작을 확인할 파일

| 동작 | 확인할 파일 |
|---|---|
| 채팅 메시지 URL 연결 | `config/urls.py`, `apps/chat/api_urls.py` |
| 요청을 받는 View | `apps/chat/api_views.py` |
| Bearer 토큰 인증 | `apps/accounts/authentication.py` |
| `content` 입력 검증 | `apps/chat/serializers.py` |
| 채팅 세션 DB 조회 | `backend/db/agent_platform.py` |
| 요청자와 세션의 팀 확인 | `backend/db/agent_platform.py` |
