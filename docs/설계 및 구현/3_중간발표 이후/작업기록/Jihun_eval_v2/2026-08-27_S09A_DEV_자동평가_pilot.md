## 구현 근거

평가용 `EvalToolLoader v2`가 첫 `document_search` handler attempt에서
`requests.exceptions.Timeout`을 발생시키고 다음 attempt에 실제 PDF에서 추출한 고정 결과를
반환한다. 운영 `_call_tool_handler()`의 retry 분류와 backoff를 그대로 통과하므로 별도 가짜
재시도 로직을 평가한 것이 아니다.

모든 업무 도구는 stub이므로 외부 조회·변경은 없다. logical tool event가 정확히 하나인 실행에
대해 handler의 두 physical outcome을 순서대로 기록해 같은 logical call의 재시도로 판정한다.

## 평가기 결함 처리

첫 시도는 handler에 전달되기 전에 제거되는 내부 예약 tool-call ID를 checker가 요구해
controlled sequence를 오판했고, Judge도 criterion과 모순되는 overall 값을 반환했다. 원시 결과는
보존하고 `INVALID_EVALUATION_INFRA` disposition으로 공식 분모에서 제외했다.
