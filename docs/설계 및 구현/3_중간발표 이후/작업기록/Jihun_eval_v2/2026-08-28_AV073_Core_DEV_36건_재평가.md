## 실패를 어떻게 해석하는가

### S01 3건

산술 검산 규칙을 추가했지만 네 세부 구성값을 답변에 모두 가져오지 못했다. 따라서
과거의 잘못된 합계 불일치는 재발하지 않았으나, 계산 수정 효과를 직접 입증하지도
못했다. 현재 주된 결함은 PDF 상세표 검색과 답변 완전성이다. 정답 날짜를 prompt에
주입하지 않고 `KNOWN_LIMITATION`·`DEFERRED_DOCUMENT_PREPROCESSING`으로 유지한다.

### S06 1건

현재 진척률, 실제 착수 범위, 완료 예정일은 올바르게 유보했다. 그러나 한 번의 답변에서

실행 실패가 아니라 Candidate 답변의 비결정적 과신 1건이다.
