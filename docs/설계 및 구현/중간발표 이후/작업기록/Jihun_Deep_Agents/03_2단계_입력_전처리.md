# 03. 2단계 — 입력 전처리

## 2단계에서 하는 일

1. 사용자 원문에서 민감정보를 마스킹한다.
2. 입력이 `/스킬이름` 형태인지 확인한다.
3. 명시적 스킬 호출이면 사용할 스킬을 조회한다.
4. 스킬 본문과 사용자 요청을 결합해 모델 입력을 다시 만든다.
5. 일반 입력이거나 스킬을 찾지 못하면 마스킹된 일반 입력을 유지한다.

성공하면 모델에 전달할 `model_input`이 확정된다.

```text
일반 입력
→ 민감정보가 마스킹된 model_input

명시적 스킬 입력
→ 스킬 본문 + 민감정보가 마스킹된 사용자 요청
```

사용자 원문 `text`는 변경하지 않고 이후 채팅 기록 저장에 사용한다.

## 전체 동작 흐름

```text
사용자 원문 text
    ↓
민감정보 마스킹
    ↓
기본 model_input 생성
    ↓
/스킬이름 형태인지 확인
    ↓
├─ 일반 입력
│      ↓
│  마스킹된 model_input 유지
│
└─ 명시적 스킬 호출
       ↓
   팀 스킬 조회
       ↓
   없으면 개인 스킬 조회
       ↓
   ├─ 스킬을 찾음
   │      ↓
   │  스킬 본문과 마스킹된 요청 결합
   │      ↓
   │  model_input 교체
   │
   └─ 스킬을 찾지 못함
          ↓
      일반 model_input 유지
          ↓
      3단계로 이동
```
