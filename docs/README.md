# SKN29 Final 2Team — AI 프로젝트 운영 코파일럿 문서

8/8 멘토링(`회의록/2026-08-08_오프라인_멘토링.md`)에서 프로젝트가
**업무 분배 서비스 → 비개발자용 Agent Platform**으로 확장됐다.
문서는 세 갈래다: **TO-BE**(새 방향 설계, 진행 중), **AS-IS**(중간발표 시점 기록),
그리고 방향과 무관한 운영·기록 문서.

## TO-BE — 새 방향 설계 (여기부터 본다)

`TO-BE/` — 서비스 구조(IA), Architecture 초안, Harness 조사, 평가 설계, E2E 시나리오.
08/12 온라인 멘토링 리뷰 대상. 세부는 `TO-BE/README.md`.

## AS-IS — 중간발표(8/6) 시점 기록

`AS-IS/` — 업무 분배 중심으로 쓰인 구 방향 문서. **현재 코드의 기록으로는 유효**하지만
TO-BE 설계 근거로 쓰지 않는다.

| 폴더 | 내용 |
|---|---|
| `AS-IS/시스템_전체_설계.md` | 8/5 정합성 기준 문서 — 중간발표 시점 시스템을 코드에서 확인해 적은 것 |
| `AS-IS/기획` | 문제정의, 기획서 v5, 중간발표 ToDo |
| `AS-IS/설계` | 파싱·청킹 공통 스키마, 아키텍처·배포, 업무분배 로직·API, 인증·권한 정책, AI 모델링 v3 |
| `AS-IS/화면설계서` | 구 IA 기준 화면설계 |
| `AS-IS/코드설명` | 운영자 콘솔 API 정리 |

|---|---|
| `개발환경` | 로컬 Docker 설치, DB 시작 가이드, AWS 구축·이전 절차. **지금 서버가 어떻게 되어 있는지는 `AWS_구성_현황.md` 한 장을 본다** — 나머지 AWS 문서는 절차서다 |
