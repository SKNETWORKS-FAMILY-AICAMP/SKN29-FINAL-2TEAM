# SKN29 Final 2Team — AI 프로젝트 운영 코파일럿 문서

프로젝트 기획·설계 문서를 성질별로 분류했다. **제출 산출물의 최신 정본은 `산출물` 폴더**, 작업 문서는 각 카테고리 폴더, 구버전은 `_archive`에 보관한다.

## 대표 문서

제출용 종합 기획서: **`산출물/[기획] 프로젝트 기획서_2Team.docx`** — 문제정의·시장조사·BM·시스템 구성·모델링·데이터 수집·R&R을 포함한 마스터 문서.
