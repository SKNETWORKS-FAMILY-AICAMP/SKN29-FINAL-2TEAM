# 시연영상 음원 및 음성 출처

## 내레이션

- 엔진: Supertonic 3
- 음성: F1
- 방식: 로컬 ONNX 추론
- 모델: Supertone/supertonic-3
- 모델 라이선스: OpenRAIL-M
- 코드 라이선스: MIT
- 공식 저장소: https://github.com/supertone-inc/supertonic

원고와 생성 과정은 로컬 환경에서 처리했으며, 내레이션 원고를 외부 음성 API로 전송하지 않았습니다.

## 배경음악

- 곡명: Soft Corporate
- 아티스트: MusicLFiles
- 재생 시간: 2분 50초
- 라이선스: Creative Commons Attribution 4.0 International
- 출처: https://commons.wikimedia.org/wiki/File:Soft_Corporate_by_MusicLFiles.ogg

영상에서는 배경음악을 반복 재생하고, 내레이션 구간에서 음량을 낮추도록 편집했습니다. 원곡은 영상 길이에 맞춰 반복·페이드·음량 조정되었습니다.
