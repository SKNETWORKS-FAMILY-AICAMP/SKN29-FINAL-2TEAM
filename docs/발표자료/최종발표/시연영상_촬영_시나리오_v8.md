# halil 시연영상 촬영 시나리오 v8

## 촬영 목표

- 최종 길이 7분 25초, 1920×1080, 100MB 이하
- 모든 장면을 한 번의 연속 촬영 순서로 사용한다.
- 실제 메뉴 순서를 유지한다.
  - `채팅 → 에이전트 → 프로젝트 → 문서 → 설정`
  - 설정 내부는 `팀 → 커넥터 → 스킬`
- 이전 메뉴로 돌아가는 컷을 사용하지 않는다.
- 생성·삭제·연결 변경·외부 등록은 촬영 중 실행하지 않는다.
- 이미 준비한 결과를 열고, 탭·상세·모달을 빠르게 조작해 정적인 장면을 줄인다.

## 촬영 동작 규칙

- 클릭 후 화면이 바뀌면 1초, 모달은 2~4초만 유지한다.
- 답변·문서 목록은 커서 이동과 짧은 스크롤을 사용한다.
- 입력을 보여줄 때는 결과가 이미 준비된 대화를 열어 대기 시간을 없앤다.
- 프로젝트·문서·설정 구간에서는 해당 메뉴를 떠나기 전 하위 기능을 모두 보여준다.
- 모달의 `저장`, `발급`, `삭제`, `완료 처리`, `사용 중지`는 누르지 않는다.
- 프로젝트의 Jira 업무 0건은 확대하지 않고, 기준 문서 후보 영역을 중심으로 촬영한다.

## 편집 레이아웃

- 브라우저 상단과 우측 스크롤바를 제거한다.
- 기능 영상은 1920×860으로 상단에 고정한다.
- 하단 220px는 짙은 남색 자막 전용 영역으로 둔다.
- 본문 자막은 44px 흰색, 최대 2줄, 하단 영역 세로 중앙에 배치한다.
- 자막 최하단은 캔버스 아래에서 최소 60px 떨어뜨린다.
- 장 제목은 하단 영역 좌측 상단에 26px 하늘색으로 표시한다.
