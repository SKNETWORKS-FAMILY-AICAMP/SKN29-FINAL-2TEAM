# halil 시연영상 스토리텔링 시나리오 v9

## 시연 목표

한빛몰 프로젝트의 핵심 요구사항을 팀 문서 근거와 함께 확인하는 하나의 사용자 여정을 보여 준다.

메뉴 나열 대신 앞 단계에서 준비한 정보가 다음 단계에서 실제로 사용되는 순서로 구성한다.

## 최종 흐름

| 시간 | 단계 | 사용자의 행동 | 다음 단계와의 연결 |
|---:|---|---|---|
| 00:00~00:08 | 목표 제시 | 시연에서 해결할 한빛몰 요구사항 확인을 제시한다. | 이후 모든 기능을 같은 목표에 연결한다. |
| 00:08~01:03 | 1. 팀 환경 준비 | 팀 프로필과 구성원을 확인하고 인사, Drive, Jira 연결 상태와 수집 범위를 점검한다. | 팀 데이터와 문서를 사용할 준비가 끝난다. |
| 01:03~02:21 | 2. 지식 기반 구성 | Drive 문서를 확인하고 한빛몰 프로젝트와 기준 문서를 설정한다. | AI가 참조할 프로젝트 범위와 근거가 정해진다. |
| 02:21~03:19 | 3. AI 역할 구성 | 프로젝트 업무 도우미에 행동 지시, 도구와 전문 서브 에이전트를 연결한다. | 질문을 처리할 역할과 위임 구조가 준비된다. |
| 03:19~04:22 | 4. 실제 업무 실행 | 한빛몰 대화를 열어 근거 답변, 처리 단계와 문서 조사 위임 기록을 확인한다. | 준비한 문서·프로젝트·에이전트가 하나의 결과로 연결된다. |
| 04:22~05:49 | 5. 반복 업무 재사용 | 개인·팀 스킬을 확인하고 새 스킬 등록 방식과 회의록 스킬 호출 결과를 보여 준다. | 팀의 반복 절차를 다음 업무에서도 재사용한다. |
| 05:49~05:56 | 마무리 | 준비부터 근거 있는 실행과 재사용까지 전체 흐름을 요약한다. | 시연 종료 |

## 편집 원칙

- 단계 전환마다 2.5~3초 목적 카드를 사용한다.
- 기능 사이의 대기 화면과 중복 이동은 제거한다.
- 실제 조작 화면은 약 1.12배속으로 편집한다.
- F1 내레이션은 다음 기능 시작 전에 끝나도록 배치한다.
- 브라우저 상단과 우측 스크롤바를 제거한다.
- 화면은 상단 1920×860, 자막 전용 영역은 하단 220px로 유지한다.
- 자막은 44px 흰색, 최대 2줄로 표시한다.

- 해상도: 1920×1080
