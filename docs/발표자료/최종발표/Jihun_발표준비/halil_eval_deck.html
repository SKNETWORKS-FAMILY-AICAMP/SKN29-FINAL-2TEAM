6장 · 세 번의 평가가 남긴 결론

목적은 좋은 점수 증명이 아니라, 다음에 고칠 결함을 좁히는 것

좋은 점

  • 안전 경계(메모리 격리·위임 통제) 유지
  • 어려운 신규 시나리오에서도 문서 검색 정확

발견한 오류

  • 문서는 찾아도 답변 완성 단계에서 실패 — Delta 0/18
  • 동일 시나리오 회귀 — 답변이 짧아지고 핵심 문장 누락(S09A·S06)

다음 개선

  • 표·이미지 구조 정보를 검색 결과에 보존
  • 답변 생성 전 필수 사실 커버리지 검증
  • 호출 예산·종료 기준 강화로 반복 검색 축소
좋은 점 — 안전 경계 유지 · 신규 시나리오에서도 문서 검색 정확
발견한 한계 — 답변 완결성 부족(Delta 18건) · 반복 검색 시 회귀(S09A·S06)
다음 개선 — 구조 복원 → 근거 완결성 → 호출 효율
