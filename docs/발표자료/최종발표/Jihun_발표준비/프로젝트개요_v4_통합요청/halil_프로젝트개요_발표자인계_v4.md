## 04. AI Agent 도입과 업무 확장

### 발표 스크립트

> “현재 기업 AI의 중요한 흐름은 단순한 기술 도입을 넘어, AI로 업무 방식을 전환하는 AX입니다. McKinsey의 2025년 조사에 따르면 기업의 62%가 AI Agent를 실험하고 있습니다. 하지만 최소 한 개 업무 기능에서 확장 중인 기업은 23%였고, 개별 업무 영역별 확장 비율은 모두 10% 이하였습니다. 즉 관심과 실험은 빠르게 늘었지만, 실제 업무로의 확장은 아직 초기 단계입니다. 저희는 그 이유를 분산된 정보와 업무 도구, 개인에게 머무는 업무 방식, 조직 차원의 운영 통제라는 세 가지 과제에서 찾았습니다.”

### 화면에서 가리킬 부분

1. `62% 최소 실험 단계 이상`
2. `23% 최소 1개 업무 기능에서 확장 중`
3. `개별 업무 영역 기준 10% 이하`
4. `업무 확장의 핵심 과제`

### 다음 장 연결

> “이러한 상황에서도 AI Agent 시장은 빠르게 성장하고 있습니다. 시장에 먼저 진입한 서비스들이 어떤 영역에 주목했는지 살펴봤습니다.”

### 상세 이해와 Q&A

- `62%`는 AI Agent를 한 개 이상 실험 중이라고 답한 기업의 비율이며, 단순한 도입 검토 비율이 아니다.
- `23%`는 전사 확장 완료가 아니라 최소 하나의 업무 기능에서 확장 중이라는 의미다.
- `62%` 안에 `23%`가 포함되므로 두 수치를 전환율이나 순차 퍼널처럼 설명하지 않는다.
- `업무 기능별 10% 이하`는 각 개별 기능에서 Agent를 확장 중이라고 답한 비율이 10%를 넘지 않았다는 뜻이다.
- 세 과제는 McKinsey가 확장 지연의 직접 원인으로 규정한 항목이 아니라, 프로젝트가 이후 구현 내용과 연결해 선택한 문제다.
- 04와 06의 세 축은 같은 순서로 설명한다: `분산된 정보와 업무 도구 → 정보·도구 연결`, `개인에게 머무는 업무 방식 → Agent 생성·실행`, `조직 차원의 운영 통제 → 운영·관리`.
- 암묵지는 별도 용어로 화면에 추가하지 않는다. `개인에게 머무는 업무 방식`으로 쉽게 표현하고, 06에서 Agent 구성·재사용으로 해결 방향을 설명한다.
- 05의 시장 규모는 HALIL의 TAM·SAM·SOM이나 확보 가능한 매출을 뜻하지 않는다. 글로벌 AI Agents 시장의 성장성과 프로젝트 방향의 시장적 타당성을 보여주는 보조 근거다.

## 05. AI Agent 시장과 선도 서비스

### 발표 스크립트

> “글로벌 AI Agent 시장은 2025년 78억 달러에서 2030년 526억 달러 규모로 성장할 전망입니다. 연평균 성장률은 46.3%입니다. Glean, Copilot Studio, Cohere North, IBM watsonx Orchestrate를 살펴본 결과, 세부 구현 방식은 달라도 세 가지 공통 영역을 확인할 수 있었습니다. 기업 정보와 업무 도구의 연결, Agent 생성과 실행, 조직 차원의 운영과 통제입니다.”

### 화면에서 가리킬 부분

1. `2025 $7.8B → 2030 $52.6B`
2. `연평균 46.3% 성장 전망`
3. 네 개 선도 서비스
4. `정보·도구 연결 · Agent 생성·실행 · 운영·통제`

### 다음 장 연결

> “저희도 시장에서 확인한 이 세 영역을 하나의 기업 Agent 플랫폼으로 구현했습니다.”

### 상세 이해와 Q&A

- 이 페이지는 투자 수익이나 점유율을 주장하는 장표가 아니라 시장 성장성과 프로젝트 방향의 타당성을 확인하는 장표다.
- `글로벌 AI Agents 시장`은 HALIL의 직접적인 TAM이나 확보 가능한 매출 규모를 의미하지 않는다.
- 네 서비스의 구조와 기능 범위가 완전히 같다는 뜻은 아니다. 화면에는 공통 영역만 남기고 차이는 필요할 때 구두로 설명한다.
- `Glean보다 우수하다`, `Copilot Studio보다 자유롭다`와 같은 주장은 하지 않는다.
- Glean은 기업 정보 연결, Agent Builder, 공유·접근 관리를 제공한다.
- Copilot Studio는 데이터·업무 도구 연결, Agent와 업무 흐름 구성, 보안·환경 관리 기능을 제공한다.
- Cohere North는 기업 데이터와 도구를 연결한 맞춤형 Agent, MCP, 워크플로우와 통제 기능을 제공한다.
- IBM watsonx Orchestrate는 Agent와 Tool 생성, 외부 시스템 연결, 오케스트레이션과 조직 단위 운영 기능을 제공한다.
- 시장 전망 수치는 MarketsandMarkets의 2025~2030 글로벌 AI Agents 시장 전망을 사용한다.

## 06. 기업 Agent 플랫폼, HALIL

### 발표 스크립트

> “HALIL은 비정형 문서를 처리해 흩어진 기업 정보를 연결하고, 커넥터와 MCP를 통해 실제 업무 도구까지 이어줍니다. 사용자는 자신의 업무 방식을 Agent로 구성해 실행하고 재사용할 수 있습니다. 또한 권한과 승인, 실행 이력을 조직 차원에서 관리할 수 있습니다. 이렇게 기업 Agent의 연결과 실행, 운영을 하나의 플랫폼에서 지원합니다.”

### 화면에서 가리킬 부분

1. `정보·도구 연결`
2. `에이전트 생성·실행`
3. `운영·관리`
4. 하단의 `하나의 플랫폼에서`

화면의 HALIL 로고는 세 영역의 상위 개념을 나타낸다. 세 영역을 각각 독립 기능으로 설명하기보다, 기업 Agent의 연결·실행·운영을 하나의 플랫폼에서 지원한다는 구조로 설명한다.

### 다음 장 연결

> “이 플랫폼을 구현하기 위해 팀에서는 각 영역을 나누어 개발했습니다.”

### 상세 이해와 Q&A

#### HALIL을 한 문장으로 정의하면?

기업의 정보와 업무 도구를 연결하고, 사용자가 Agent를 구성해 실행하며, 조직 차원에서 권한·승인·실행 결과를 관리하는 기업 업무 활용 Agent 플랫폼이다.

#### 왜 플랫폼이라고 부르는가?

하나의 고정 업무만 수행하는 것이 아니라 Connector, MCP, 문서, Tool, Sub-agent를 조합해 Agent를 구성할 수 있고, 운영 측에서 연결 서비스, 모델, 권한, 승인과 실행 현황을 관리하는 구조를 제공하기 때문이다.

#### 평가 대신 실행 추적이라고 쓴 이유는?

개요에서는 정식 성능평가와 운영 기능이 혼동되지 않도록 실제 OPS에서 확인 가능한 실행 현황과 사용 기록을 중심으로 표현했다. 구체적인 품질 평가는 뒤의 평가 파트에서 설명한다.

## 발표자가 기억할 네 문장

1. 기업의 62%가 Agent를 실험하고 있지만 실제 업무 기능으로의 확장은 아직 초기다.
2. 우리는 분산된 정보와 업무 도구, 개인에게 머무는 업무 방식, 운영 통제에 주목했다.
3. 성장하는 시장의 선도 서비스에서도 연결·실행·운영이라는 공통 영역을 확인했다.
4. HALIL은 이 세 영역을 하나의 기업 업무 활용 Agent 플랫폼으로 구현했다.

## 표현상 주의사항

- `62%에서 23%로 전환됐다`고 말하지 않는다. 23%는 62%에 포함된 집단이다.
- 세 과제를 McKinsey가 직접 규정했다고 말하지 않는다.
- 선도 서비스와 HALIL의 구조가 완전히 동일하다고 말하지 않는다.
- 구현하거나 검증하지 않은 기능을 확정적으로 말하지 않는다.
- 화면에 제거한 회색 부제목은 읽지 않고, 필요한 맥락만 각 페이지 스크립트의 첫 문장으로 전달한다.
