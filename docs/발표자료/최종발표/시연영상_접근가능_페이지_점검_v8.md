## 4. 확인한 주요 모달·상세 상태

- 채팅: 에이전트 선택, 대화 검색, 대화별 도구 선택
- 에이전트: 기본 도구 30종 분류, 테스트 MCP의 `add`·`echo`, 서브 에이전트 선택
- 프로젝트: 새 프로젝트 입력, 기준 문서 변경 후보와 내용 유사도
- 문서: Drive 폴더, 내 파일, 공유 받은 파일
- 팀: 하위 조직 직원 대상 초대 코드 발급 모달
- 커넥터: HR·Drive·Jira 제공자 선택, Drive 폴더 설정 및 101개 파일 미리보기
- 스킬: 새 스킬 직접 작성, `SKILL.md` 업로드, 개인 스킬 수정, 팀 스킬 내용 보기

## 5. 촬영 전 준비 상태

- `문서 조사 에이전트`, `프로젝트 업무 도우미`를 즐겨찾기에 추가함.
- 프로젝트 근거 대화 `프로젝트 기준 문서 핵심 요구사항 3가지 정리`를 생성함.
  - 프로젝트: 한빛몰 주문·정산 시스템 고도화 구축
  - 에이전트: 프로젝트 업무 도우미
  - 결과: 문서 조사 에이전트 위임, 47초 작업 과정, 요구사항 3개와 원문 근거
- 스킬 대화 `8월 31일 프로젝트 회의록 정리`를 생성함.
  - 개인 스킬 `meeting-notes-format` 적용
  - 결과: 결정 사항·할 일·미결 쟁점·다음 회의로 정리

## 6. 현재 제약

- Jira 커넥터는 연결 상태지만 자동 등록된 Jira 프로젝트가 0개다.
- 두 프로젝트 상세의 Jira 업무도 0건이다.
- 사용자 시연에서는 운영자 콘솔에 접근할 수 없다. 운영자 콘솔은 별도 운영자 계정과 별도 녹화가 필요하다.
- Jira 재연결은 외부 OAuth와 실제 프로젝트 동기화를 수반할 수 있어 이번 사전 준비에서는 수행하지 않았다.
