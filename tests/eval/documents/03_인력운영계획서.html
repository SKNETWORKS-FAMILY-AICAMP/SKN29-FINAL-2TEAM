2. 역할별 담당 과업과 필수 기술

2.1 프로젝트 관리자

사업 전체의 일정·품질·위험을 관리하고 발주사와의 창구 역할을 한다. 특정 과업의 개발을 직접 수행하지 않는다.

  • 필수 경험: 결제 또는 정산 도메인 SI 사업 PM 2회 이상
  • 필수 기술: 일정 관리 도구(Jira), 위험 관리 대장 운영

2.2 백엔드 리드

담당 과업: 주문 도메인 재설계 및 상태기계 구현(3.1), 결제대행 이중화 및 장애 자동 전환(3.3). 두 과업의 설계를 직접 작성하고 백엔드 개발자의 산출물을 검토한다.

  • 필수 기술: Java 21, Spring Boot 3.x, 도메인 주도 설계, 상태기계 설계 경험
  • 필수 기술: 결제(PG) 연동 경험 2건 이상, 멱등 처리 설계 경험
  • 우대: Oracle에서 PostgreSQL로의 전환 경험

2.3 백엔드 개발자

담당 과업: 정산 엔진 신규 개발(3.2), 재고 동기화 이벤트 기반 전환(3.4). 정산은 고급 2인이, 재고는 중급 1인이 DevOps/SRE와 함께 맡는다.

  • 필수 기술: Java 21, Spring Boot 3.x, PostgreSQL 15, JPA
  • 필수 기술: Apache Kafka 기반 이벤트 처리 (재고 담당)
  • 필수 기술: 금액 계산의 정밀도 처리(BigDecimal, 반올림 정책) 경험 (정산 담당)

2.4 프론트엔드 개발자

담당 과업: 판매자 정산 포털 신규 구축(3.5).

  • 필수 기술: React 19, TypeScript 5.x, 상태관리(TanStack Query)
  • 필수 기술: 웹 접근성 KWCAG 2.2 AA 대응 경험
  • 우대: 대용량 표 가상 스크롤 구현 경험

2.5 데이터 엔지니어

담당 과업: 레거시 데이터 이관 및 검증(3.6). 정산 엔진(3.2)의 검증 도구 개발에 30% 범위로 참여한다.

  • 필수 기술: Apache Airflow, SQL 튜닝, Oracle과 PostgreSQL 양쪽 경험
  • 필수 기술: 대사(reconciliation) 검증 파이프라인 구축 경험

2.6 DevOps/SRE

담당 과업: 관측성 체계 구축(3.7). 결제 이중화(3.3)의 자동 전환 운영 설계와 재고 이벤트 기반 전환(3.4)의 Kafka 운영을 지원한다.

  • 필수 기술: Kubernetes, Helm, GitHub Actions
  • 필수 기술: OpenTelemetry, Prometheus, Grafana, Loki
  • 필수 기술: Apache Kafka 운영(파티션 설계, 컨슈머 지연 관리)

2.7 QA 엔지니어

담당 과업: 통합 성능시험 및 안정화(3.8).

  • 필수 기술: k6 또는 JMeter 기반 부하시험 설계
  • 필수 기술: 장애 주입 시험 설계 경험
  • 필수 기술: 시험 시나리오 및 결함 관리 체계 운영

2.8 UI/UX 디자이너

담당 과업: 판매자 정산 포털 신규 구축(3.5)의 화면 설계.

  • 필수 기술: Figma, 디자인 시스템 구성
  • 필수 기술: 접근성을 고려한 색과 대비 설계

3. 인력 운영 규칙

  • 투입 인력 교체는 발주사 사전 승인을 받는다. 승인 없는 교체는 계약 위반으로 본다.
  • PM과 백엔드 리드는 사업 전 기간 동일인을 유지한다.
  • 주 3일 이상 발주사에 상주하며, 상주일은 화·수·목을 원칙으로 한다.
  • 투입률 100% 미만 인력은 투입 일정을 월 단위로 사전 공유한다.
